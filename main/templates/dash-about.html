About the Project

ThreatHunt is a tool that uses Event Viewer or log files to identify anomalies or intrusions against services such as SSH. It allows users to create firewall rules to permit or block specific connections, enhancing system protection. Additionally, it logs remote address connections to perform lookups and retrieve detailed information about those addresses.
